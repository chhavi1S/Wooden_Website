# 🪵 Wooden Website

A beautifully designed and animated **Wooden Website** built using **HTML** and **CSS**. This project showcases a nature-inspired web layout with custom animations and responsive design, ideal for furniture businesses, interior design brands, or eco-friendly products.

---

## 🌲 Overview

This is a static website that highlights wooden products or services with a smooth user experience. Built from scratch using just **HTML5** and **CSS3**, the website uses **CSS animations** to enhance the look and feel of the site, giving it a natural, elegant appeal.

---

## 🎨 Features

- 🍂 Elegant wooden-style theme  
- ✨ Smooth CSS animations for transitions and elements  
- 🖥️ Fully responsive layout (mobile, tablet, desktop)  
- 📦 Clean and semantic HTML structure  
- 💡 Lightweight and fast performance (no JavaScript)

---

## 🔧 Technologies Used

- **HTML5** – for semantic structure and content  
- **CSS3** – for styling and layout  
- **CSS Animations & Transitions** – for visual effects  
- **Google Fonts** – for typography (optional)
